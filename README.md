# ИТМО · Машинное обучение · 2026/27

Статическая страница курса. В docs/ находятся три лекции в PDF, пример EDA на Python, две домашние работы 2026 года, TAIGA, ведомость, правила оценивания и архив предыдущего потока. Сайт работает без JavaScript и сторонних зависимостей.

## Публикация

В Settings → Pages выберите Deploy from a branch, ветку main, папку /docs, затем Save. Адрес: https://itmo-se-ml.github.io/.

Корневой index.html также ведёт на docs/: публикация корня ветки main тоже поддерживается.

## Обновления

- site.json — ссылки на бота, ведомость, папку прошлогодних материалов, чат и дата обновления.
- build.py — содержание и генерация docs/index.html.
- archive.json — презентации предыдущего потока.
- docs/style.css — оформление и мобильная версия.
- docs/materials/ — файлы для скачивания.

После правки выполните `python3 build.py` и закоммитьте обновлённый docs/index.html вместе с исходниками. Pages публикует готовые файлы.

Локальный просмотр: `python3 -m http.server 8000 --directory docs`.
